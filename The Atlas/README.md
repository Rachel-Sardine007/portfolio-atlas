# The Atlas

An interactive maritime portfolio built with React, TypeScript, Vite, and React Router.

## Architecture

- `src/components/map`: responsive interactive portfolio map
- `src/components/projects`: reusable project cards
- `src/components/quests`: local explorer journal UI
- `src/components/layout`: shared navigation and page shell
- `src/data`: typed, editable portfolio content
- `src/hooks`: persistent localStorage quest state
- `src/pages`: route-level portfolio experiences
- `src/styles`: design tokens, layouts, animations, dark mode, and print styles
- `src/types`: shared TypeScript interfaces

## Content

- `src/data/projects.ts`: projects, links, stacks, features, and case-study copy
- `src/data/portfolio.ts`: skills, islands, quests, experience, education, and learning
- `src/pages/AboutPage.tsx`: personal narrative and thinking framework
- `src/pages/PilatesPage.tsx`: movement practice
- `src/pages/ContactPage.tsx`: email/social links and form-service connection point
- `public/assets/Tianyu-Shi-CV.pdf`: the final CV file
